Helmlab

Helmlab defines color spaces for generating colors (gradients, palettes, gamut mapping) and for measuring color differences, and publishes their reference code.

Current definition: Helmlab 2026

Helmlab 2026 is defined by the outputs of helmlab 1.0.0 on npm and PyPI; 1.0.1 and 1.0.2 give the same outputs. The specification writes the definition out step by step, with test vectors and conformance levels for other implementations.

IdentifierWhat it names
helmgenGenSpace in Lab coordinates, for generating colors
helmgenlchGenSpace in LCh coordinates (lightness, chroma, hue)
helmlab-metricMetricSpace in its base form, for measuring color differences
ΔE helmlabColor difference computed from helmlab-metric coordinates
helmlab-metric-neutral (reserved)MetricSpace with the neutral correction (Appendix B); hl.metric in the helmlab package returns this form

Install

npm i helmlab
pip install helmlab

API reference: API.md. Changes by version: CHANGELOG.md.

Other implementations

These libraries are maintained outside Helmlab: Color.js, ColorAide and color-space.

Known issues

  • hl.metric in the helmlab package returns the neutral-corrected form, so its a and b differ from those of Color.js and ColorAide, which implement helmlab-metric. color-space 3.5.0 and 3.6.0 ship the neutral-corrected form under the name helmlab-metric. Conformance of these libraries: Section 8 of the specification.
  • The paper differs from the reference code in places; the errata are in Section 11 of the specification. Known limitations of the definition: Section 10.
